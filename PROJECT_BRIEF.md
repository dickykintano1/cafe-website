# Project Brief

Last updated: 2026-10-26
Status: Development

## 1. Overview

Project name: Mockup Cafe Website - Ardell's Coffee and Pastry
Website type: Informational & Reservation System
Client / owner: Fictional Entity - Ardell's Coffee and Pastry

Short description:
To build a mockup website for a fictional cafe called Ardell's Coffee and Pastry. The website will be used to showcase the cafe's menu, location, and reservation system. It will also be used to showcase the cafe's brand identity and values.

## 2. Audience

Primary audience:
Potential Customers looking for a cozy cafe to relax and enjoy coffee and pastries.

Main visitor needs:
- See the website menu and prices
- See the location and hours of the cafe
- Make a reservation

Likely usage context:
- Browsing on a phone
- Comparing services

## 3. Purpose and Main Action

Business / owner goal:
To build a website that is both visually appealing and functional. 
It should be easy to navigate, use, and informational.

Visitor goal:
To be able to find the cafe's menu, location, and hours, 
and make a reservation.

Primary action:
To make a reservation.

Secondary actions:
- [viewing the menu]
- [viewing the open schedule]
- [learning about the cafe]

Success criteria:
- The website represents and tell the brand's aesthetic and values
- The menu is easy to navigate
- The website provides information needed for both walk-in and reservation customers
- The reservation system works properly
